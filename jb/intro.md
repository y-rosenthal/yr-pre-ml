# What is Machine Learning?

*Prerequisite material for getting started*

Machine learning starts with data. Before a model can learn anything, someone has to load the data, look at it,
clean it and put it into the shape that the model needs. In Python, two packages do almost all of that work:
**NumPy** and **pandas**. This book teaches them, one small step at a time, with business examples.

Each chapter is a notebook. The "Open in Colab" button at the top of a chapter opens it in Google Colab, where
you can run the code in your browser. The first chapter also shows how to run the same code in Thonny and in
other Python editors.

This book is for readers who know basic Python, for example from *Think Python*.
