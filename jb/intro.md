# What is Machine Learning?

*Prerequisite material for getting started*

Machine learning starts with data. Before a model can learn anything, someone has to load the data, look at it,
clean it, and put it into the shape that the model needs. In Python, two packages do almost all of that work:
**NumPy** and **pandas**. This book teaches them, one small step at a time, with business examples: customers,
stores, sales, deliveries and advertising.

The book is for readers who know basic Python, for example from *Think Python*: variables, lists, loops, `if`
statements, functions and dictionaries. You need no statistics beyond an average.

## How the book is organized

- **Using this book** shows how to run the code in Google Colab and in Thonny.
- **Why NumPy and pandas?** starts at the end: a complete machine-learning example, and what a model learns. You
  see that most of the code prepares data.
- **NumPy arrays** and **Working with arrays** teach NumPy: arrays, arithmetic on whole arrays at once, Boolean
  masks, summaries, and two-dimensional arrays, the shape of the data that models use.
- The three **pandas** parts teach tables of data: reading a file, describing it, selecting and filtering rows,
  making new columns, sorting, grouping, charts, and preparing data for a model.
- **Putting it together** has two projects with new data: one guided, one on your own.
- The **appendices** have the common errors and their fixes, a cheat sheet, the datasets, and further reading.

## How to use a chapter

Each chapter is a notebook. Click **Open in Colab** at the top of a chapter (or the rocket button at the top of the
page) to run its code in your browser, change it, and try your own ideas. Read the chapter *Colab, Thonny and other
IDEs* first: it shows how to run the same code in Thonny.

Each chapter ends with **practice questions**, from easy to hard. Try each one before you click **Answer**.
