11. New columns and sorting#

A data file rarely has every column that we need. The sales file has the units, the price and the discount of each sale, but not the money that the sale brought in. In this chapter, we compute new columns from the old ones, tidy up the column names, and sort the rows to answer questions such as “Which were our five biggest sales?”

In this chapter, you will learn to:

  • add a column computed from other columns, and round it;

  • make a column from a part of a text column, with .str[:7];

  • make a column from a condition, with the loc rule;

  • rename and drop columns;

  • sort the rows by one or two columns, find the top rows, give them a fresh index, and use nlargest.

import pandas as pd

DATA_URL = "https://raw.githubusercontent.com/y-rosenthal/yr-pre-ml/main/data/"

We use the sales of a store chain again: 2,000 sales in one year, one row for each sale.

sales = pd.read_csv(DATA_URL + "sales.csv")
sales.head()
date store region category units price discount
0 2025-01-01 S1 North Clothing 3 46.99 0.1
1 2025-01-01 S8 West Grocery 9 2.99 0.0
2 2025-01-01 S2 North Grocery 11 5.99 0.0
3 2025-01-01 S8 West Grocery 9 11.99 0.0
4 2025-01-01 S5 East Grocery 13 3.99 0.2

11.1. A new column from other columns#

The revenue of a sale is the money it brought in: the units, times the price, minus the discount. A discount of 0.1 means 10% off, so the customer pays 1 - 0.1 = 0.9 of the price. We compute it for every row at once, and store it in a new column:

sales["revenue"] = sales["units"] * sales["price"] * (1 - sales["discount"])
sales[["units", "price", "discount", "revenue"]].head()
units price discount revenue
0 3 46.99 0.1 126.873
1 9 2.99 0.0 26.910
2 11 5.99 0.0 65.890
3 9 11.99 0.0 107.910
4 13 3.99 0.2 41.496

The new column revenue appears at the right end of the table. Check row 0: 3 units at $46.99 with a discount of 0.1 give 3 × 46.99 × 0.9 = 126.873.

The arithmetic works row by row, as it does for arrays of the same length: pandas multiplies the units of row 0 by the price of row 0, and so on, for all 2,000 rows, with no loop. The rule:

  • df["new"] = ... with a new name adds a column;

  • with the name of a column that exists, it replaces that column.

11.2. Rounding a column#

Money has two decimal places. round(2) rounds every value of a column, and we put the result back in the same column:

sales["revenue"] = sales["revenue"].round(2)
sales[["units", "price", "discount", "revenue"]].head()
units price discount revenue
0 3 46.99 0.1 126.87
1 9 2.99 0.0 26.91
2 11 5.99 0.0 65.89
3 9 11.99 0.0 107.91
4 13 3.99 0.2 41.50

126.873 became 126.87, and 41.496 (row 4) became 41.50. The name revenue is on both sides of =, so the rounded column replaces the old one.

11.3. A column from text: .str#

The column date holds text such as "2025-03-14". To compare months, we want just the year and the month, "2025-03": the first seven characters. For one Python string, we would write date[:7]. For a whole column, we put .str before the slice:

sales["month"] = sales["date"].str[:7]
sales[["date", "month"]].head()
date month
0 2025-01-01 2025-01
1 2025-01-01 2025-01
2 2025-01-01 2025-01
3 2025-01-01 2025-01
4 2025-01-01 2025-01

.str tells pandas to do a text operation on each value of the column, here the slice [:7]. Every date of January now has the month 2025-01. (pandas has many other text operations after .str; we need only this one.)

Try it: sales["month"].nunique() counts the different months. Is the answer what you expect?

11.4. A column from a condition#

Let’s label each sale “small” or “large”: large when it has 8 units or more. We do it in two steps. First, every row gets "small": one value on the right of = fills the whole column. Then the loc rule of the chapter Filtering rows changes the rows that match the condition:

sales["size"] = "small"
sales.loc[sales["units"] >= 8, "size"] = "large"
sales[["units", "size"]].head()
units size
0 3 small
1 9 large
2 11 large
3 9 large
4 13 large

Row 0 has 3 units, so it stays small. The rows 1 to 4 have 8 or more units, so they became large.

Try it: count the large sales with (sales["size"] == "large").sum(). What share of the 2,000 sales is that?

11.5. Renaming columns#

The name size is short, but it is not very clear, and a DataFrame also has an attribute sales.size (the number of values in the table, as for arrays). Let’s call the column order_size. rename takes a dictionary from the old names to the new names:

sales = sales.rename(columns={"size": "order_size"})
list(sales.columns)

['date',
 'store',
 'region',
 'category',
 'units',
 'price',
 'discount',
 'revenue',
 'month',
 'order_size']

The column is now called order_size. Like most pandas methods, rename does not change the table itself: it returns a new one, so we assign it back to sales. list(...) turns the column names into a plain Python list, which is easy to read.

The dictionary can hold several names at once, for example {"units": "quantity", "category": "product_type"}.

11.6. Dropping columns#

Our table now has 10 columns. For a report about revenue, we do not need all of them. drop(columns=[...]) returns the table without the columns in the list:

report = sales.drop(columns=["date", "region", "price", "discount"])
report.head()
store category units revenue month order_size
0 S1 Clothing 3 126.87 2025-01 small
1 S8 Grocery 9 26.91 2025-01 large
2 S2 Grocery 11 65.89 2025-01 large
3 S8 Grocery 9 107.91 2025-01 large
4 S5 Grocery 13 41.50 2025-01 large

report has six columns: store, category, units, revenue, month and order_size. The table sales still has all ten, because we assigned the result to a new name.

Common mistake: writing sales.drop(columns=["date"]) alone on a line and expecting sales to change. The line shows a table without date, but sales keeps it. To keep the change, assign it: sales = sales.drop(columns=["date"]).

11.7. Sorting the rows#

sort_values("revenue") returns the rows in order of their revenue, from the smallest:

report.sort_values("revenue").head()
store category units revenue month order_size
110 S4 Grocery 1 2.84 2025-01 small
1080 S2 Grocery 1 2.99 2025-07 small
815 S5 Grocery 2 3.58 2025-05 small
52 S7 Home 1 4.74 2025-01 small
1661 S2 Grocery 2 4.78 2025-10 small

The smallest sale brought in $2.84: one Grocery unit. Look at the index: 110, 1080, 815, … Each row kept its label, as we saw in the chapter Selecting with loc and iloc.

11.8. The top 5#

For the biggest sales first, add ascending=False. Then head() gives the top 5:

report.sort_values("revenue", ascending=False).head()
store category units revenue month order_size
732 S7 Electronics 3 1697.97 2025-05 small
300 S3 Electronics 3 1679.97 2025-02 small
1343 S1 Electronics 3 1514.97 2025-09 small
1281 S7 Electronics 3 1388.97 2025-08 small
1212 S5 Electronics 3 1373.97 2025-08 small

The five biggest sales were all Electronics sales of 3 units, between about \(1,374 and \)1,698. Note their order_size: our rule called them small, because it looked at the units, not the money. Which column we sort by decides what “big” means.

This “sort, then head()” pattern answers many business questions: the top 5 customers, the 10 slowest deliveries, the cheapest products.

11.9. Sorting by two columns#

To sort by two columns, give a list of names. The rows are sorted by the first column, and rows with the same value there are sorted by the second. ascending can take a list too, one True or False for each column:

report.sort_values(["store", "revenue"], ascending=[True, False]).head()
store category units revenue month order_size
1343 S1 Electronics 3 1514.97 2025-09 small
489 S1 Electronics 2 1079.98 2025-04 small
1345 S1 Electronics 2 991.78 2025-09 small
1324 S1 Electronics 2 905.98 2025-08 small
1269 S1 Electronics 3 878.97 2025-08 small

The stores are in order from S1, and within store S1, the biggest sale comes first. So the first row is the biggest sale of store S1: $1,514.97.

11.10. A fresh index: reset_index#

After sorting, the labels are mixed up. For a report, the labels 0, 1, 2, … often read better. reset_index(drop=True) gives the rows new labels from 0, and throws away the old ones:

top5 = report.sort_values("revenue", ascending=False).head()
top5 = top5.reset_index(drop=True)
top5
store category units revenue month order_size
0 S7 Electronics 3 1697.97 2025-05 small
1 S3 Electronics 3 1679.97 2025-02 small
2 S1 Electronics 3 1514.97 2025-09 small
3 S7 Electronics 3 1388.97 2025-08 small
4 S5 Electronics 3 1373.97 2025-08 small

The same five sales, now labelled 0 to 4. Without drop=True, pandas would keep the old labels in a new column named index.

11.11. A shortcut: nlargest#

“Sort from the largest, then take the first rows” is so common that pandas has a shortcut, nlargest:

report.nlargest(5, "revenue")
store category units revenue month order_size
732 S7 Electronics 3 1697.97 2025-05 small
300 S3 Electronics 3 1679.97 2025-02 small
1343 S1 Electronics 3 1514.97 2025-09 small
1281 S7 Electronics 3 1388.97 2025-08 small
1212 S5 Electronics 3 1373.97 2025-08 small

The same five sales as the top 5 above, with their original labels. nlargest(5, "revenue") reads “the 5 rows with the largest revenue”. nsmallest does the opposite.

11.12. Summary#

  • df["new"] = ... adds a column (or replaces one with that name): sales["revenue"] = sales["units"] * sales["price"] * (1 - sales["discount"]).

  • sales["revenue"].round(2) rounds every value; assign it back to keep it.

  • sales["date"].str[:7] takes the first seven characters of each text value.

  • A column from a condition: sales["size"] = "small", then sales.loc[sales["units"] >= 8, "size"] = "large".

  • df.rename(columns={"old": "new"}) and df.drop(columns=[...]) return a new table; assign the result.

  • df.sort_values("col") sorts from the smallest; ascending=False from the largest; a list of columns sorts by several. head() after sorting gives a top 5.

  • reset_index(drop=True) gives the labels 0, 1, 2, …; df.nlargest(5, "col") gives the 5 largest rows.

Answer

In "2025-03-14", the day is at the positions 8 and 9, so .str[8:] takes it. .str[-2:] (the last two characters) works too.

sales["day"] = sales["date"].str[8:]

11.13.4. Question 4 (Medium)#

Add a column discounted that is "yes" for the sales with a discount and "no" for the others. How many sales had a discount?

Answer

Fill the column with "no", then change the matching rows with loc. 982 sales had a discount.

sales["discounted"] = "no"
sales.loc[sales["discount"] > 0, "discounted"] = "yes"
(sales["discounted"] == "yes").sum()

11.13.8. Question 8 (Challenge)#

Replace the two sizes with three: "small" for fewer than 4 units, "medium" for 4 to 7 units, and "large" for 8 units or more. Put them in a new column size3 and count the sales of each size.

Answer

Start with "small" everywhere, then use loc once for each other size. The medium sales need two conditions. Most sales are small: 900 small, 785 medium and 315 large.

sales["size3"] = "small"
sales.loc[(sales["units"] >= 4) & (sales["units"] <= 7), "size3"] = "medium"
sales.loc[sales["units"] >= 8, "size3"] = "large"
for size in ["small", "medium", "large"]:
    print(size, (sales["size3"] == size).sum())
