7. Series and DataFrames#

A NumPy array keeps its values by position: the first value, the second value, and so on. Business data has names: store S3, the column sales, the region West. pandas is the Python package for tables of data with such names. In this chapter, we meet its two building blocks: the Series (one column) and the DataFrame (a table).

In this chapter, you will learn to:

  • create a Series with labels, and get its values and its labels;

  • compute with a Series as with an array, and select a value by its label;

  • create a DataFrame from a dictionary of lists;

  • select one column (a Series) or several columns (a DataFrame);

  • describe a DataFrame with .shape, len(), .columns, .index and .dtypes;

  • add a new column to a DataFrame.

import pandas as pd

By custom, pandas is imported as pd, just as NumPy is imported as np. pandas is built on NumPy: a pandas column of numbers keeps its values in a NumPy array.

7.1. Numbers need labels#

A chain has six stores, S1 to S6. We know last month’s sales of each store, in thousands of dollars. As a NumPy array, the sales are six numbers: [52.3, 48.1, 61.7, 39.5, 45.0, 53.4]. Which number belongs to store S4? We have to remember that the stores are in order, and count. With hundreds of stores, that is easy to get wrong.

pandas keeps a label with every value, so that we can ask for “the sales of S4” by name.

7.2. A Series: values with labels#

The simplest pandas object is a Series: a sequence of values, each with a label. We can make one from a list:

monthly_sales = pd.Series([52.3, 48.1, 61.7, 39.5, 45.0, 53.4])
monthly_sales

0    52.3
1    48.1
2    61.7
3    39.5
4    45.0
5    53.4
dtype: float64

In Thonny: a last reminder. In a Thonny script, wrap the last line of a cell in print() to see its value, here print(monthly_sales). From now on, the book takes this for granted.

pandas shows the Series in two columns. The right column holds the values. The left column, 0 to 5, is the index: the labels of the values. We gave no labels, so pandas numbered the values from 0, like the positions of an array. The last line, dtype: float64, is the type of the values, as for a NumPy array.

Now let’s give the values better labels, and give the Series a name:

monthly_sales = pd.Series(
    [52.3, 48.1, 61.7, 39.5, 45.0, 53.4],
    index=["S1", "S2", "S3", "S4", "S5", "S6"],
    name="sales",
)
monthly_sales

S1    52.3
S2    48.1
S3    61.7
S4    39.5
S5    45.0
S6    53.4
Name: sales, dtype: float64

Now the index holds the store names, and the last line also shows the name of the Series, sales. index= takes a list of labels, one for each value, in the same order. name= is optional. It becomes the column name when a Series is part of a table.

The rule: a Series is a column of values with an index of labels. All its values have one dtype, as in a NumPy array.

7.3. The values and the index#

A Series has two parts, and we can get each one. .to_numpy() gives the values as a NumPy array:

monthly_sales.to_numpy()

array([52.3, 48.1, 61.7, 39.5, 45. , 53.4])

This is the kind of array we used in the chapter From lists to NumPy arrays: the same six values, without the labels. You may also see .values in other code. For a column of numbers, it gives the same array. We use .to_numpy(), whose name says what it does.

.index gives the labels:

monthly_sales.index

Index(['S1', 'S2', 'S3', 'S4', 'S5', 'S6'], dtype='object')

The labels form a pandas object of their own, an Index. Its dtype is 'object', which is how pandas 2 marks text. In pandas 3, the dtype is 'str'. We come back to dtypes below.

7.4. Arithmetic works as with arrays#

A Series computes like a NumPy array: an operation with a number is done on every value. Say that each store must grow its sales by 10%. The target of each store is:

monthly_sales * 1.10

S1    57.53
S2    52.91
S3    67.87
S4    43.45
S5    49.50
S6    58.74
Name: sales, dtype: float64

Each value was multiplied by 1.10, and the labels stayed: we can still see which target belongs to which store. The summaries of the chapter Comparisons and Boolean masks, such as .sum(), .mean() and .max(), work too.

Try it: run monthly_sales > 50. You get a Series of True and False: a mask, with labels. Which stores sold more than 50 thousand dollars? (The chapter Filtering rows uses such masks to choose rows.)

7.5. Selecting a value by its label#

To get one value, we put its label in square brackets, as with a key in a dictionary:

monthly_sales["S3"]

np.float64(61.7)

Store S3 sold 61.7 thousand dollars. A Series is a little like a dictionary whose keys are the labels, but it can also compute like an array.

Note: Colab shows np.float64(61.7): one number taken out of pandas is a NumPy number, as in the chapter Indexing, slicing and arithmetic.

Common mistake: writing monthly_sales[0] to get the first value. The square brackets of a Series look for a label, and 0 is not one of the labels here. Colab’s pandas 2 still gives the first value, with a FutureWarning; pandas 3 gives KeyError: 0. To select by position, use iloc, which the chapter Selecting with loc and iloc explains.

7.6. A DataFrame: a table of columns#

Most business data is a table: one row for each store (or customer, or sale), and one column for each fact. pandas calls a table a DataFrame. The easiest way to make one is from a dictionary: each key is a column name, and each value is the list of the values in that column.

stores = pd.DataFrame({
    "store": ["S1", "S2", "S3", "S4", "S5", "S6"],
    "city": ["Boston", "Atlanta", "Chicago", "Denver", "Miami", "Seattle"],
    "region": ["East", "South", "North", "West", "South", "West"],
    "employees": [12, 8, 15, 6, 9, 10],
    "sales": [52.3, 48.1, 61.7, 39.5, 45.0, 53.4],
})
stores
store city region employees sales
0 S1 Boston East 12 52.3
1 S2 Atlanta South 8 48.1
2 S3 Chicago North 15 61.7
3 S4 Denver West 6 39.5
4 S5 Miami South 9 45.0
5 S6 Seattle West 10 53.4

Each row is one store, and each column is one fact about it: its name, its city, its region, its number of employees, and its monthly sales in thousands of dollars. On the left is the index, 0 to 5. We gave no index, so pandas numbered the rows.

The rule: a DataFrame is a table of columns that share one index. Each column is a Series. Different columns can hold different types (text in one, numbers in another), but all the values in one column have one dtype. All the lists must have the same length: one value for each row.

In general code, and in the summaries of this book, a DataFrame is often called df, and a Series s.

7.7. One column is a Series#

To select a column, we put its name in square brackets:

stores["sales"]

0    52.3
1    48.1
2    61.7
3    39.5
4    45.0
5    53.4
Name: sales, dtype: float64

The result is a Series: the values of the column, with the index of the DataFrame on the left, and the column name as the Series’ name. Everything we did with monthly_sales works here too: stores["sales"].mean() is the average sales of a store, and stores["employees"].sum() the number of employees of the whole chain.

Common mistake: stores["Sales"], with a capital S, gives KeyError: 'Sales'. Column names are case-sensitive: write them exactly as they are in the table.

7.8. Several columns: double brackets#

To select several columns, we put a list of column names inside the square brackets. That makes two pairs of brackets: the outer pair selects, and the inner pair makes the list.

stores[["city", "sales"]]
city sales
0 Boston 52.3
1 Atlanta 48.1
2 Chicago 61.7
3 Denver 39.5
4 Miami 45.0
5 Seattle 53.4

The result is a DataFrame with only these two columns, in the order of the list. Even a list with one name gives a DataFrame: stores[["sales"]] is a table with one column, while stores["sales"] is a Series. (The chapter What does a model learn? wrote customers[["visits_per_month"]] for this reason: scikit-learn wants the predictors as a table.)

7.9. The size and the parts of a table#

.shape gives the size of a DataFrame as (rows, columns), as for a 2-D array in the chapter Two-dimensional arrays. len() gives the number of rows:

print(stores.shape)
print(len(stores))

(6, 5)
6

The table has 6 rows and 5 columns. For a DataFrame, len counts the rows, not the columns.

.columns gives the column names, and .index the row labels:

print(stores.columns)
print(stores.index)

Index(['store', 'city', 'region', 'employees', 'sales'], dtype='object')
RangeIndex(start=0, stop=6, step=1)

The column names are an Index of text, like the labels of monthly_sales (dtype='object', or dtype='str' in pandas 3). We can loop over them, or make a list with list(stores.columns).

The row labels are a RangeIndex: pandas’ short way to write the numbers 0, 1, …, 5. It starts at 0 and stops before 6, like np.arange(6). When we read a data file in the next chapter, its rows get such an index too.

7.10. The type of each column#

.dtypes (with an s) gives the dtype of every column:

stores.dtypes

store         object
city          object
region        object
employees      int64
sales        float64
dtype: object

The number columns have NumPy’s dtypes: int64 for whole numbers (employees) and float64 for numbers with decimals (sales). The text columns store, city and region have the dtype object (or str in pandas 3): that is how pandas marks text. Ignore the last line, dtype: object: it is the dtype of this list of dtypes itself, and it is the same in both versions.

Why look at dtypes? Most arithmetic and summaries, such as mean(), make sense only for number columns. And machine-learning models accept only numbers: in the chapter A first machine-learning example, fit failed because of the text column region. .dtypes is the quickest way to find such columns.

7.11. Adding a column#

To add a column, we assign a list to a new column name. The list needs one value for each row. Here is the year in which each store opened:

stores["opened"] = [2012, 2018, 2009, 2021, 2016, 2019]
stores
store city region employees sales opened
0 S1 Boston East 12 52.3 2012
1 S2 Atlanta South 8 48.1 2018
2 S3 Chicago North 15 61.7 2009
3 S4 Denver West 6 39.5 2021
4 S5 Miami South 9 45.0 2016
5 S6 Seattle West 10 53.4 2019

The new column appears at the right. (If a column with that name already exists, the assignment replaces its values.)

More often, a new column is computed from other columns. The arithmetic works row by row, as for two arrays of the same length. Here are the sales of each store divided by its number of employees:

stores["sales_per_employee"] = stores["sales"] / stores["employees"]
stores
store city region employees sales opened sales_per_employee
0 S1 Boston East 12 52.3 2012 4.358333
1 S2 Atlanta South 8 48.1 2018 6.012500
2 S3 Chicago North 15 61.7 2009 4.113333
3 S4 Denver West 6 39.5 2021 6.583333
4 S5 Miami South 9 45.0 2016 5.000000
5 S6 Seattle West 10 53.4 2019 5.340000

For each row, pandas divided that row’s sales by that row’s employees. Store S3 in Chicago has the highest sales (61.7) and the most employees, but the lowest sales per employee: about 4.11 thousand dollars a month. Store S4 in Denver has the lowest sales and the fewest employees, but the highest sales per employee: about 6.58. The chapter New columns and sorting shows more ways to make columns.

Common mistake: a list with the wrong number of values. stores["opened"] = [2012, 2018] gives ValueError: Length of values (2) does not match length of index (6). The list must have exactly one value for each row.

7.12. Summary#

  • pandas (import pandas as pd) works with tables of data. It is built on NumPy.

  • A Series is a column of values with an index of labels: pd.Series([...], index=[...], name="..."). .to_numpy() gives its values as a NumPy array, and .index its labels. Arithmetic and summaries work as for arrays, and s["S3"] selects a value by its label.

  • A DataFrame is a table of columns that share one index: pd.DataFrame({"col": [...], ...}).

  • df["col"] gives one column, as a Series. df[["a", "b"]] (double brackets) gives a DataFrame with those columns.

  • df.shape is (rows, columns), len(df) is the number of rows, df.columns gives the column names, and df.index the row labels.

  • df.dtypes gives the type of each column: int64 and float64 for numbers, object (or str in pandas 3) for text.

  • df["new"] = [...] or df["new"] = df["a"] / df["b"] adds a column.

7.14.1. Question 1 (Easy)#

A café counts its visitors: 120 on Monday, 95 on Tuesday, 143 on Wednesday, 110 on Thursday and 160 on Friday. Make a Series visitors with the labels "Mon" to "Fri" and the name "visitors". Then show the number of visitors on Wednesday.

Answer

The list of values and the list of labels must be in the same order. Wednesday had 143 visitors.

visitors = pd.Series(
    [120, 95, 143, 110, 160],
    index=["Mon", "Tue", "Wed", "Thu", "Fri"],
    name="visitors",
)
print(visitors)
print(visitors["Wed"])

7.14.2. Question 2 (Easy)#

Select the column region of stores twice: once as a Series, and once as a DataFrame with one column. How can you tell the two outputs apart?

Answer

One pair of brackets gives a Series. Its output ends with the line Name: region, dtype: object (or dtype: str in pandas 3). Double brackets give a DataFrame: the column name region is at the top of the column, and there is no Name: line.

print(stores["region"])
print(stores[["region"]])

What is the average number of employees of a store? And what are the highest monthly sales of a store? Use the columns of stores.

7.14.6. Question 6 (Hard)#

Make a DataFrame products with four products and three columns: product ("pen", "notebook", "stapler", "lamp"), price (1.50, 3.25, 8.99, 24.00) and units (120, 80, 15, 6). Show its dtypes. Then add a column revenue, the price times the units, and show the table. Which product brings the most revenue?

Answer

product is text (object, or str in pandas 3), price is float64 and units is int64. The notebook brings the most revenue: 260 dollars.

products = pd.DataFrame({
    "product": ["pen", "notebook", "stapler", "lamp"],
    "price": [1.50, 3.25, 8.99, 24.00],
    "units": [120, 80, 15, 6],
})
print(products.dtypes)
products["revenue"] = products["price"] * products["units"]
products

7.14.7. Question 7 (Challenge)#

A colleague types the number of employees of four new stores, but one value goes in as text: new_employees = pd.Series([12, 8, "15", 6]). What is the dtype of this Series? What happens if you call new_employees.sum(), and why? How do you fix the data?

Answer

The dtype is object, in pandas 2 and in pandas 3: the Series mixes numbers and text, so it cannot be int64 (and pandas 3 uses str only when every value is text). .dtype gives the dtype of one Series, as for an array. new_employees.sum() fails with TypeError: unsupported operand type(s) for +: 'int' and 'str': Python cannot add a number and a text. The fix is to write 15 without quotes. Then the dtype is int64, and the sum is 41.

new_employees = pd.Series([12, 8, "15", 6])
print(new_employees.dtype)
fixed = pd.Series([12, 8, 15, 6])
print(fixed.dtype)
print(fixed.sum())
