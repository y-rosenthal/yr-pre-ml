1. A first machine-learning example#

Before we learn the tools, let’s see where they lead. In this chapter, we build three small machine-learning models that predict how much a customer will spend in a year. You do not need to understand every line yet: the goal is to see the whole workflow once, from a data file to a prediction. Then we notice something important about the code.

In this chapter, you will learn to:

  • describe the machine-learning workflow in words: data, predictors, target, training, testing, error;

  • run a complete example with three models, and compare their errors;

  • see that most of the code prepares data with pandas and NumPy, which is what the rest of this book teaches.

import pandas as pd
from sklearn.model_selection import train_test_split
from sklearn.linear_model import LinearRegression
from sklearn.tree import DecisionTreeRegressor
from sklearn.ensemble import RandomForestRegressor
from sklearn.metrics import mean_absolute_error

DATA_URL = "https://raw.githubusercontent.com/y-rosenthal/yr-pre-ml/main/data/"

The first cell imports the tools: pandas for data, and five tools from scikit-learn (imported as sklearn), the most popular Python package for machine learning. Run it once before the other cells.

1.1. The business question#

A store chain has a loyalty program. For each member, it knows the age, the region, how many months the person has been a customer, how often they visit, and how much they spend per visit. It also knows how much each member spent last year.

The marketing team asks: for a new member, how much will they spend in a year? A good guess helps to decide how much to invest in each customer.

Machine learning (ML) answers such questions from examples. We give the computer many customers whose spending we know, and it finds a rule that connects the facts about a customer to the spending. Then we use the rule for customers whose spending we do not know.

1.3. Step 2: choose the target and the predictors#

The column we want to predict is the target. Here it is annual_spend. The columns we use to predict it are the predictors (also called features). By custom, the predictors are named X and the target y:

X = customers.drop(columns="annual_spend")
y = customers["annual_spend"]
X.shape

(500, 5)

X has the 5 predictor columns, and y has the one target column.

It fails. Read the last line of the error message: the model cannot convert a string such as 'South' to a number (float). Models work only with numbers, and the region column holds text.

That is not the only problem. Some values are missing. The first five rows above happen to be complete, but other rows are not. pandas shows a missing value as NaN (“Not a Number”). Let’s count the missing values in each column:

customers.isna().sum()

months_as_customer     0
visits_per_month       0
avg_basket            11
annual_spend           0
dtype: int64

14 ages and 11 basket amounts are missing. LinearRegression, like many other models, also refuses missing values.

This is normal. Real business data almost always has text columns and missing values. Before any model can learn, someone has to prepare the data. That someone is you, with pandas.

1.5. Step 3: prepare the data#

We make two changes (the chapter Preparing data for machine learning explains them in detail):

  1. Drop the rows that have a missing value. We keep most of the customers.

  2. Replace the text column region with number columns: one column for each region, which is True (1) when the customer is in that region and False (0) when not.

clean = customers.dropna()
clean = pd.get_dummies(clean, columns=["region"])
clean.shape

(475, 9)

475 customers remain, and region became four columns (one for each region). Let’s look at the new columns, next to the target (a list of column names inside [...] selects those columns):

Now we choose X and y again, from the clean data:

X = clean.drop(columns="annual_spend")
y = clean["annual_spend"]

1.6. Step 4: split the data into training and test sets#

How do we know whether a model is good? We cannot judge it on the customers it learned from: a model can simply remember them. So we hide some customers from the model while it learns, and test it on them later.

train_test_split does this. It puts 75% of the rows in a training set and 25% in a test set, chosen at random. random_state=42 fixes the random choice, so that you get the same split as this book.

X_train, X_test, y_train, y_test = train_test_split(X, y, test_size=0.25, random_state=42)
X_train.shape, X_test.shape

((356, 8), (119, 8))

356 customers to learn from, and 119 to test on.

1.7. Step 5: train three models#

We train three kinds of model on the same training set. Each one learns a different kind of rule:

  • linear regression finds the best straight-line formula, such as “spend = a + b × visits + c × basket + …”;

  • a decision tree learns a set of yes/no questions, such as “Is visits_per_month above 4.5?”;

  • a random forest builds many different decision trees and averages their answers.

fit is the step where a model learns from data. It is the same one line for every model. (Colab shows a short description of the last model under the cell; you can ignore it.)

linear = LinearRegression()
linear.fit(X_train, y_train)

tree = DecisionTreeRegressor(max_depth=5, random_state=42)
tree.fit(X_train, y_train)

forest = RandomForestRegressor(n_estimators=200, random_state=42)
forest.fit(X_train, y_train)

1.8. Step 6: predict, and measure the error#

Now each model predicts the spending of the 119 test customers, whom it has never seen. predict returns one number for each customer:

forest_predictions = forest.predict(X_test)
forest_predictions[:5]

array([1682.64605, 3650.08555, 3507.31895, 1953.2757 , 2120.72995])

Compare them with what these five customers really spent:

y_test.head()

392    1535.82
441    3805.29
9      3092.05
75     1953.60
369    2085.82
Name: annual_spend, dtype: float64

The predictions are close, but not exact. To summarize how close they are, we use the mean absolute error (MAE): for each customer, take the difference between the prediction and the real value, ignore the sign, and average these differences over all test customers. The MAE is in dollars: “on average, the prediction is off by this many dollars”. Smaller is better.

for name, model in [("linear regression", linear), ("decision tree", tree), ("random forest", forest)]:
    predictions = model.predict(X_test)
    error = mean_absolute_error(y_test, predictions)
    print(f"{name:18} MAE: ${error:,.0f}")

linear regression  MAE: $364
decision tree      MAE: $445
random forest      MAE: $250

The three models make errors of different sizes. Here, the random forest predicts best. The single decision tree predicts worst: with only five levels of yes/no questions, it can give only a limited number of different answers. Linear regression is in between. A customer’s yearly spending is roughly visits per month × basket × 12: two numbers multiplied together. A straight-line formula adds numbers, so it can follow a multiplication only roughly. The random forest averages many trees, and that gives smoother, closer predictions.

Try it: change max_depth=5 to max_depth=2, then run the training cell and the cell above again. Does the decision tree get better or worse?

1.9. The important point#

Look back at the code of this chapter and sort the lines into two groups:

Lines that prepare the data (pandas, NumPy)

Lines that do machine learning (scikit-learn)

pd.read_csv(...), head(), shape

train_test_split(...)

isna().sum(), dropna()

LinearRegression(), DecisionTreeRegressor(...), RandomForestRegressor(...)

pd.get_dummies(...)

fit(...)

drop(columns=...), clean["annual_spend"]

predict(...)

choosing X and y, slicing [:5]

mean_absolute_error(...)

The machine-learning part is short, and it is almost the same for every model: create, fit, predict, measure. Most of the work, and most of the thinking, is in getting the data ready. Data professionals often say that they spend most of their time on this part.

The next chapters teach exactly that part: NumPy, the package for fast arrays of numbers (scikit-learn works on NumPy arrays), and pandas, the package for tables of data. At the end of the book, you do the whole workflow yourself, on new data.

1.10. Summary#

  • Machine learning finds a rule that predicts a target (here annual_spend) from predictors (the other columns), using examples whose target is known.

  • The workflow: read the data → prepare it (no text, no missing values) → choose X and y → split into training and test sets → fit models on the training set → predict the test set → compare the errors.

  • The MAE (mean absolute error) is the average size of the prediction errors, in the units of the target.

  • Models need numbers, and many models, such as LinearRegression, also refuse missing values. Preparing the data is most of the work, and it is done with pandas and NumPy.

1.12.2. Question 2 (Easy)#

Why did the first model.fit(X, y) fail? What second problem in the data would also have stopped it?

Answer

The text column region stopped it: the models work only with numbers. The missing values (NaN) would also stop LinearRegression. dropna() removed the rows with missing values, and pd.get_dummies replaced the text column with number columns.

1.12.3. Question 3 (Easy)#

Why do we test a model on customers that it did not see while it learned?

Answer

A model can remember the customers it learned from, so it may look very good on them and still predict badly for new customers. The test set shows how well the model predicts for customers it has never seen, which is the job we want it to do.

1.12.6. Question 6 (Hard)#

Split the data with test_size=0.5 instead of 0.25 (keep random_state=42). Train a new random forest on the new training set, and compute its MAE on the new test set. Is it bigger or smaller than before? Why might that be?

Answer

Here the MAE is about \(310, against about \)250 before: bigger. With half of the data for testing, the forest learns from only 237 customers instead of 356. (The test set changes too, so the numbers are not exactly comparable.)

forest2 = RandomForestRegressor(n_estimators=200, random_state=42)
forest2.fit(X_train2, y_train2)
mean_absolute_error(y_test2, forest2.predict(X_test2))

1.12.7. Question 7 (Challenge)#

Train a random forest that uses only two predictors, visits_per_month and avg_basket. Compare its MAE with the forest that uses all the predictors. What does the result suggest about the other columns?

Answer
