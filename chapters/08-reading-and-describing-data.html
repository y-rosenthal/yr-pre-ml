8. Reading and describing data#

So far, we typed our data by hand. Real business data comes in files, often with thousands of rows. In this chapter, we read a file of 2,000 sales into a DataFrame and take a first look at it: how big it is, what its columns hold, and what its numbers look like. This first look is the first step of every data project, machine learning included.

In this chapter, you will learn to:

  • read a CSV file into a DataFrame with pd.read_csv;

  • look at the first and the last rows with head() and tail();

  • describe a table with .shape, .columns, .dtypes and info();

  • read the summary statistics of describe(): count, mean, std, min, quartiles and max;

  • list the different values of a text column with unique() and nunique();

  • find the columns that have missing values.

import pandas as pd

DATA_URL = "https://raw.githubusercontent.com/y-rosenthal/yr-pre-ml/main/data/"

DATA_URL is the web address of the folder that holds the book’s data files (the chapter Colab, Thonny and other IDEs explains it).

8.1. CSV files#

The most common file format for tables is CSV, short for comma-separated values. A CSV file is plain text: one line for each row, with the values separated by commas. The first line holds the column names. Here are the first lines of the file sales.csv:

date,store,region,category,units,price,discount
2025-01-01,S1,North,Clothing,3,46.99,0.1
2025-01-01,S8,West,Grocery,9,2.99,0.0
2025-01-01,S2,North,Grocery,11,5.99,0.0

Each line is one sale of a store chain: the day, the store and its region, the product category, the number of units, the price of one unit in dollars, and the discount as a fraction of the price (0.1 is 10%). The appendix The datasets describes every file and column.

8.2. Reading a CSV file#

pd.read_csv reads a CSV file and returns a DataFrame:

sales = pd.read_csv(DATA_URL + "sales.csv")
sales.head()
date store region category units price discount
0 2025-01-01 S1 North Clothing 3 46.99 0.1
1 2025-01-01 S8 West Grocery 9 2.99 0.0
2 2025-01-01 S2 North Grocery 11 5.99 0.0
3 2025-01-01 S8 West Grocery 9 11.99 0.0
4 2025-01-01 S5 East Grocery 13 3.99 0.2

DATA_URL + "sales.csv" joins two strings into the full address of the file. pd.read_csv reads the file, takes the column names from the first line, and makes one row of the DataFrame from each other line. It also chooses a dtype for each column, from the values in it.

head() shows the first five rows. It is the first thing to look at after reading a file: did the columns come out right, and what do the values look like?

Note: to read a file that is saved on your own computer, give its name instead of the address: pd.read_csv("sales.csv") reads the file sales.csv in the folder of your Thonny script. The appendix The datasets has a link to each file.

head() can show more rows. We give it the number:

These are the first ten sales, from the first days of January: the rows are in date order. tail() shows the last five rows:

sales.tail()
date store region category units price discount

8.4. The size, the columns and the dtypes#

As in the chapter Series and DataFrames, .shape gives the number of rows and of columns:

sales.shape

(2000, 7)

2,000 sales, and 7 columns. .columns lists the column names:

sales.columns

Index(['date', 'store', 'region', 'category', 'units', 'price', 'discount'], dtype='object')

pandas took these names from the first line of the file. (The dtype at the end is 'object' in pandas 2 and 'str' in pandas 3.) .dtypes gives the type of each column:

sales.dtypes

date         object
store        object
region       object
category     object
units         int64
price       float64
discount    float64
dtype: object

units holds whole numbers (int64), and price and discount hold numbers with decimals (float64). The other four columns hold text: object (or str in pandas 3). Note that date is text too: pandas does not turn text that looks like a date into a date by itself. That is fine for this book. The chapter New columns and sorting takes the month out of this text.

8.5. A report on the table: info()#

info() gives the facts of the last sections, and a little more, in one report:

sales.info()

<class 'pandas.core.frame.DataFrame'>
RangeIndex: 2000 entries, 0 to 1999
Data columns (total 7 columns):
 #   Column    Non-Null Count  Dtype  
---  ------    --------------  -----  
 0   date      2000 non-null   object 
 1   store     2000 non-null   object 
 2   region    2000 non-null   object 
 3   category  2000 non-null   object 
 4   units     2000 non-null   int64  
 5   price     2000 non-null   float64
 6   discount  2000 non-null   float64
dtypes: float64(2), int64(1), object(4)
memory usage: 109.5+ KB

Let’s read it from the top:

  • The first line says that sales is a DataFrame.

  • RangeIndex: 2000 entries, 0 to 1999: there are 2,000 rows, with the index 0 to 1999.

  • Data columns (total 7 columns), then one line for each column: its position (#), its name, its non-null count and its dtype.

  • The dtypes line counts the columns of each dtype.

  • The last line says how much memory the table uses (about 110 KB).

The non-null count is the number of values that are not missing (“null” is another word for a missing value). Here, every column has 2000 non-null values, as many as there are rows: no value is missing in sales.csv. We meet missing values at the end of this chapter.

Note: info() prints its report itself, so in Thonny, too, you write sales.info() without print(). With print(sales.info()), you see the report and then the word None: info() prints, but it returns no value.

8.6. Summary statistics: describe()#

describe() computes summary statistics for every number column:

sales.describe()
units price discount
count 2000.000000 2000.000000 2000.000000
mean 4.474500 72.828000 0.055350
std 2.856121 122.254803 0.071073
min 1.000000 1.990000 0.000000
25% 2.000000 9.990000 0.000000
50% 4.000000 26.990000 0.000000
75% 6.000000 71.240000 0.100000
max 16.000000 597.990000 0.200000

The text columns are not there: describe() uses only the number columns. Each row of the result is one statistic:

  • count: the number of values that are not missing; 2000 in each column.

  • mean: the average. A sale has 4.47 units on average, and the average price is $72.83.

  • std: the standard deviation, a typical distance of the values from the mean. A small std means that the values are close together, and a large one that they are spread out.

  • min and max: the smallest and the largest value. A sale has from 1 to 16 units, and the prices go from \(1.99 to \)597.99.

  • 25%, 50%, 75%: the quartiles. Sort the values from the smallest to the largest: the 25% value is a quarter of the way through the list, the 50% value halfway, and the 75% value three quarters of the way. The 50% value is the median, the middle value: half of the values are at or below it.

What do these numbers tell a manager?

  • Prices: the median price is \(26.99, but the mean is \)72.83. So half of the sales have a price of \(26.99 or less, and a few expensive items (up to \)597.99) pull the mean up. When the mean and the median are far apart, the median is often the better “typical” value. The large std of the prices (about 122) says the same thing: the prices are very spread out.

  • Units: the 75% value is 6, so at least three quarters of the sales have 6 units or fewer. Sales of 16 units are rare.

  • Discounts: the 25% and the 50% values are 0, so at least half of the sales had no discount.

Try it: the numbers have many decimals. Run sales.describe().round(2) to round them to two decimals.

8.7. Text columns: unique() and nunique()#

For a text column, a mean or a median makes no sense. Instead, we ask: which different values does the column have? unique() lists each value once:

sales["store"].unique()

array(['S1', 'S8', 'S2', 'S5', 'S6', 'S7', 'S3', 'S4'], dtype=object)

The eight stores, S1 to S8, in the order in which they first appear in the file. In pandas 2 (Colab), the result is a NumPy array with dtype=object; pandas 3 shows a <StringArray> with the same values. nunique() counts the different values:

sales["store"].nunique()

8

There are 8 stores. When a column has many different values, this count is easier to read than the list. (The chapter Grouping and summarizing counts how many sales each store had.)

8.8. Selecting columns: a recap#

Selecting columns works as in the chapter Series and DataFrames: a list of names gives a DataFrame, and one name gives a Series. head() works on both:

sales[["date", "store", "units"]].head()
date store units
0 2025-01-01 S1 3
1 2025-01-01 S8 9
2 2025-01-01 S2 11
3 2025-01-01 S8 9
4 2025-01-01 S5 13

These are three columns of the first five sales. One column is a Series, and the summaries of arrays work on it:

sales["units"].sum()

np.int64(8949)

The chain sold 8,949 units during the year. (Colab shows np.int64(8949): the NumPy form of the number, as in the chapter Indexing, slicing and arithmetic.)

8.9. Missing values: a first look#

The file customers.csv, from the chapter A first machine-learning example, describes 500 customers. Let’s read it and look at its info():

customers = pd.read_csv(DATA_URL + "customers.csv")
customers.info()

<class 'pandas.core.frame.DataFrame'>
RangeIndex: 500 entries, 0 to 499
Data columns (total 6 columns):
 #   Column              Non-Null Count  Dtype  
---  ------              --------------  -----  
 0   age                 486 non-null    float64
 1   region              500 non-null    object 
 2   months_as_customer  500 non-null    int64  
 3   visits_per_month    500 non-null    float64
 4   avg_basket          489 non-null    float64
 5   annual_spend        500 non-null    float64
dtypes: float64(4), int64(1), object(1)
memory usage: 23.6+ KB

There are 500 rows (RangeIndex: 500 entries) and 6 columns. But two columns have fewer than 500 non-null values: age has 486, and avg_basket (the average amount spent per visit) has 489. So 14 ages and 11 basket amounts are missing. pandas shows a missing value as NaN (“Not a Number”). info() is the quickest way to see which columns have missing values, and how many.

The count row of describe() shows the same thing:

customers[["age", "avg_basket"]].describe()
age avg_basket
count 486.000000 489.000000
mean 46.401235 51.539121
std 16.330022 14.823895
min 18.000000 11.950000
25% 33.000000 41.460000
50% 46.000000 51.560000
75% 61.000000 61.270000
max 75.000000 96.610000

The count of age is 486, not 500: describe() skips the missing values, and computes the other statistics from the values that are there. The average customer is about 46 years old and spends about $51.54 per visit.

Missing values are a problem for machine learning: many models, such as LinearRegression, refuse them. That is why the chapter A first machine-learning example dropped those rows before fit. The chapter Preparing data for machine learning shows how to drop them or fill them in.

8.10. Summary#

  • pd.read_csv(DATA_URL + "sales.csv") reads a CSV file into a DataFrame.

  • head() and tail() show the first and the last five rows; head(10) shows the first ten.

  • .shape gives (rows, columns), .columns the column names, and .dtypes the type of each column (text is object, or str in pandas 3).

  • info() prints the number of rows, and for each column its non-null count and its dtype. A non-null count below the number of rows means that values are missing.

  • describe() gives the count, mean, std, min, quartiles (25%, 50% = the median, 75%) and max of each number column.

  • For a text column, unique() lists the different values, and nunique() counts them.

8.12.8. Question 8 (Challenge)#

The revenue of a sale is units * price * (1 - discount). Compute it for every sale as a Series in a variable revenue (with arithmetic on columns, as in the chapter Series and DataFrames), and describe it. What is the median revenue of a sale? What is the total revenue of the year, rounded to cents?

Answer

The median revenue of a sale is about \(89.09, and the total revenue is \)318,227.41. The mean revenue (about $159) is much bigger than the median, as for the prices: a few big sales pull the mean up.

revenue = sales["units"] * sales["price"] * (1 - sales["discount"])
print(revenue.describe())
print(round(revenue.sum(), 2))
